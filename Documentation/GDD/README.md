
# EcoGenesis 3D — Game Design Document

## Información general

EcoGenesis 3D es un videojuego de aventura y exploración en tercera persona desarrollado en Unity 3D.

El proyecto aborda la gestión inadecuada de residuos sólidos mediante una experiencia interactiva de educación ambiental.

## Objetivos de Desarrollo Sostenible

- ODS 11: Ciudades y comunidades sostenibles.
- ODS 12: Producción y consumo responsables.
- ODS 15: Vida de ecosistemas terrestres.

## Diseño del juego

El Game Design Document (GDD) contiene el concepto, las mecánicas, la narrativa, los personajes, la dirección artística y la planificación técnica del videojuego.
